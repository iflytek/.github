# iFLYTEK Open Source

Welcome to the official GitHub organization of iFLYTEK Open Source.

We open up practical AI infrastructure, developer tooling, and real-world engineering practices to the global developer community, helping build an open-source ecosystem that is useful, scalable, and production-ready.

Among them, **Astron** is iFLYTEK's enterprise-grade AI Agent open-source project matrix, designed to support the key capabilities required to build and scale **SuperAgents**, including:

- **Agent workflow orchestration**
- **RPA automation**
- **MCP tool ecosystem**
- **Enterprise skill management**
- **Multi-agent collaboration**

## Astron Open Source Matrix

Astron is not a single repository. It is an open-source project matrix that evolves around enterprise AI Agent scenarios and end-to-end execution needs.

### [astron-agent](https://github.com/iflytek/astron-agent)

An enterprise-grade, commercial-friendly agent workflow platform that provides core capabilities for **workflow orchestration, MCP tool integration, multi-agent collaboration, team collaboration, and production deployment**. It serves as a foundational platform for building next-generation SuperAgents.

### [astron-rpa](https://github.com/iflytek/astron-rpa)

An agent-ready RPA automation suite for desktop applications, web systems, and business process automation. It helps agents connect to real enterprise systems and extends AI from "can think" to "can execute".

### [skillhub](https://github.com/iflytek/skillhub)

An open-source enterprise skill registry and governance platform that supports **skill publishing, version management, RBAC governance, auditability, and self-hosted deployment**, helping teams build reusable, governable, and distributable skill assets.

### [iFly-Skills](https://github.com/iflytek/iFly-Skills)

The official skill collection covering speech, OCR, translation, proofreading, and multimodal capabilities. It provides a rich foundation for agent workflows, enterprise skill ecosystems, and scenario-based AI solutions.

### [astronclaw-tutorial](https://github.com/iflytek/astronclaw-tutorial)

A hands-on tutorial project around AstronClaw and related agent workflows, helping developers and users understand, experience, and adopt the Astron open-source ecosystem more quickly.
